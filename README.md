## Purpose

This is my portfolio and engineering journal for the 16-week VLSIGuru AI Literacy Layer. I use it to record what I learned, what I tried, what I verified, and what is still uncertain. The habit I am practicing is: ask, inspect, verify, document, reflect.

- Explaining AI, ML, deep learning, generative AI and agents clearly
- Checking AI output against reliable sources
- Testing AI results instead of trusting them
- Documenting experiments and evidence

This repository is public and contains only my own, non-confidential work.
