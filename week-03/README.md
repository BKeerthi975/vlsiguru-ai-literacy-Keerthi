## How AI helped
I used Claude as a learning assistant (explanations, drafting notes, prompt feedback)
and web search to find primary sources. Verilator experiments were run on Verilator 5.020
and the claim check was cross-checked against Verilator's own issue tracker and
project/vendor articles. I edited everything into my own words.
No confidential RTL or proprietary material was uploaded to any AI service
(the example design is a simple 4-bit counter written for this exercise).
